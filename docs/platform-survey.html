2. 重点：HaoETF —— 唯一把实时期货折进估值的公开平台

它怎么算（官网口径，见 qdii 页页脚）

  • 最新估值 / 最新溢价：基于 T-2 日净值 + 跟踪指数，即「T-1 口径」，收盘后可核对。
  • 实时估值 / 实时溢价：基于「T-1 日估值 + 实时期货」滚动修正——A 股交易时段美股现货休市，期货是唯一实时价格代理，这正是你要的第二段逻辑。
  • 仓位用移动平均法估算（近期约 95%），汇率用人民币汇率中间价（每日 9:15 更新后重算）。
  • 单基金页给出自校验列「估值误差」（估算估值 vs 实际净值，近期多在 ±0.1% 以内）。

  • 站内路径：实时数据 → ETF / T+0 QDII → 欧美市场（jisilu.cn/data/qdii/），溢价率按已公布净值计算，QDII 有净值延迟。
  • 集思录 2026 年初下线了自家基金估值数据，「套利工具箱」插件（Edge / Chrome 商店可搜）在集思录页面注入「QDII-LOF 实时估值溢价率」：按跟踪指数当日表现估算，弥补 T-2 净值延迟的信息盲区；同时给 LOF/ETF 溢价率增强和「跟踪比」。
  • 适合：盘后复盘 + 限购状态 + 份额变动联合判断套利可行性（高溢价 + 限购宽松 = 潜在机会）。

WiseETF（专做纳指 / 标普500 的场内外路径比较）

  • 页面：wise-etf.com/today/etf-premium（溢价榜，可按时点排序）、wise-etf.com/chooser（场内 vs 场外路径比较）。
  • 口径 = 同日收盘价 / 同日净值；把「今日申购额度、溢价、费率、跟踪误差、成交情况」放在同一页，附带溢价分级预警。
  • 注意：当日动态字段有时显示「待确认」，用前先看数据日期。

金快查（全市场折溢价监控）

  • LOF 全市场折溢价监控 + 套利测算；ETF 全市场实时折溢价、含跨境 QDII 溢价榜；数据来源为东方财富、天天基金、沪深交易所；支持自选与推送提醒，数据约 5 分钟刷新。
  • 未披露是否用期货修正实时估值，QDII 部分应按「已公布净值口径」理解。

券商 App / 付费终端

  • 东财、同花顺、通达信、华泰等 App：行情页直接给「溢价率」，均为「现价 / 最新公布净值」，QDII 天然滞后一晚（券商口径亦是 T-1 / T-2）。
  • Wind / Choice / iFinD：适合拉长历史溢价序列做统计，不解决实时性。

5. 第二段价差的原料：期货行情与汇率

  • 标普500期货（E-mini / Micro E-mini）：英为财情（延迟约 10–15 分钟）、以及任意行情终端（TradingView、富途、老虎、新浪财经）。
  • 汇率：人民币汇率中间价，每日 9:15 披露（HaoETF 即采用此值，2026-10-14 为 6.7249）。
  • 官方净值：基金公司官网 / 天天基金，T 日晚间公布（QDII 实际挂牌净值以晚间确认为准）。

6. 自己拼「真实溢价率」的配方

# 盘中实时口径（剔除时差）
实时估值(t) = 官方净值(T-1) × [1 + SP500期货当日涨跌幅 × 估算仓位] × [1 + USD/CNY汇率变动]
实时溢价率 = 场内现价 ÷ 实时估值(t) − 1

# 收盘后的「硬」数字
T日真实溢价率 = T日收盘价 ÷ T日晚公布的T日净值 − 1

# 第二段价差（一级市场 vs 标普500期货）
期货现货价差 = SP500期货点位 − SP500现货点位（基差 + 隔夜累计涨幅）
今日示例：7867.58 − 7805.45 ≈ +0.79%
  • 步骤：① 定时抓英为财情期货价与人民币中间价；② 取官方净值（T-1）与估算仓位；③ 按上式滚估值；④ 与场内实时价比对得「实时溢价率」。
  • 校验方法：与实际公布的净值算「估值误差」，误差稳定在 ±0.3% 内说明仓位与汇率假设可用。
共性注意事项：① 各平台「溢价率」口径不同（T-1 / T-2 / 同日 / 期货修正），数值不可跨平台直接对比，用前先确认数据日期；② QDII 净值延迟 + 限购使溢价具有粘性，513500 已在 5%–11% 运行数月，基金公司多次发布「溢价风险提示公告」；③ 高溢价买入的亏损来源是溢价回落而非指数下跌——判断依据应是「期货修正后的真实溢价率」而非券商 App 里的 T-1 口径数字。
调研方法：2026-10-14 对各平台首页 / QDII 专区 / 单基金页实时抓取核对口径说明；行情数字为当日盘中快照，仅作口径示例，不构成投资建议。

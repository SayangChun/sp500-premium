# sp500-premium

标普500场内基金「真实溢价率」看板 —— 只看**标普500指数**，剔除信息科技、生物科技、医疗保健等衍生品；所有数值跟随市场行情实时刷新。

> 打开即看：启用 GitHub Pages 后访问 `https://sayangchun.github.io/sp500-premium/`
> （仓库 Settings → Pages → Source 选 `main` 分支根目录，Save 后约 1 分钟生效）

## 它解决什么问题

QDII 基金净值按美股交易日披露、次日晚间才公布，而 A 股白天先交易——券商 App 显示的「溢价率」是拿今天的场内价除以昨晚的净值，隔夜美股的涨跌完全没算进去，会系统性高估或低估真实溢价。

本项目的**真实溢价率**用标普500期货把这段时差补上：

```
估算净值 = 最新净值 × (1 + (期货现价 ÷ 净值日期货日收盘 − 1) × 仓位) × (1 + 汇率变动)
真实溢价率 = 场内现价 ÷ 估算净值 − 1
未修正溢价 = 场内现价 ÷ 最新净值 − 1        ← 券商App的滞后口径
```

实测与 HaoETF 的实时口径逐只对比，误差 ≤0.08%（差异来源：HaoETF 用每日 9:15 人民币中间价，本项目用 CNH 实时价）。

## 数据怎么流动

```
浏览器（每秒级实时，无服务端）
 ├─ 场内行情    东方财富 push2（3秒） → 腾讯行情 qt.gtimg.cn（兜底）
 ├─ 期货       腾讯 qt.gtimg.cn hf_ES（10秒，国内直连） → Yahoo ES=F（兜底）
 ├─ 汇率        Yahoo Finance CNY=X（影响已钳制在 ±0.5%）
 ├─ 官方净值    天天基金 fundmobapi（5分钟）
 └─ HaoETF 对照 data/sp500.json ← GitHub Actions（每5分钟抓取并自动提交）

注：全部接口均支持浏览器跨域（CORS）；任一接口失败自动降级，
    页面会保留上一次有效值并在状态徽章上标注「快照/中断」。
```

```

```

## 已知口径说明

- **净值日期**：QDII 净值按美股交易日披露、次日晚间公布；页面显示的「最新净值」可能滞后一个交易日。
- **期货锚点**：用净值日期当天 E-mini S&P 500 的日收盘价作锚，期货实时价相对它的变动即指数累计涨跌（含隔夜）。
- **仓位**：默认 95%（HaoETF 移动平均估算），页面滑块可在 85%–100% 间做敏感性测算。
- **HaoETF 对照**：来自 haoetf.com 单基金页，其口径用人民币中间价（9:15 更新），与本站 CNH 实时价存在约 0.05%–0.1% 系统差。

# sp500-premium

标普500场内基金「真实溢价率」看板 —— 只看**标普500指数**，剔除信息科技、生物科技、医疗保健等衍生品；所有数值跟随市场行情实时刷新。

> 打开即看：启用 GitHub Pages 后访问 `https://sayangchun.github.io/sp500-premium/`
> （仓库 Settings → Pages → Source 选 `main` 分支根目录，Save 后约 1 分钟生效）

## 它解决什么问题

QDII 基金净值按美股交易日披露、次日晚间才公布，而 A 股白天先交易——券商 App 显示的「溢价率」是拿今天的场内价除以昨晚的净值，隔夜美股的涨跌完全没算进去，会系统性高估或低估真实溢价。

本项目的**真实溢价率**用标普500期货把这段时差补上（与交易所 IOPV、同花顺等平台口径一致）：

```
r_idx = (标普500现货最近收盘 ÷ 净值日收盘 − 1) + (ES期货实时价 ÷ 期货昨结 − 1)
估算净值 = 最新净值 × (1 + r_idx × 仓位) × (1 + Δ汇率)
真实溢价率 = 场内现价 ÷ 估算净值 − 1     ← 剔除中美时段错位，≈交易所 IOPV 口径
T-1净值口径 = 场内现价 ÷ 最新净值 − 1    ← 券商App常见滞后口径，与真实口径差「隔夜美股×仓位」
```

两段式含义：①「隔夜段」用标普500现货日线（净值日收盘 → 最近美股收盘）；②「今日段」用 E-mini 期货实时价相对其昨结的变动（A股时段美股现货休市，期货是唯一实时代理）。
实测与 HaoETF 官方实时口径逐只对比误差 ≤0.1%（差异来源：HaoETF 用每日 9:15 人民币中间价，本项目汇率日内变动按 0 处理）。

## 数据怎么流动

```
浏览器（秒级实时，无服务端）
 ├─ 场内行情    东方财富 push2（3秒） → 腾讯行情 qt.gtimg.cn（兜底）
 ├─ ES 期货      腾讯 qt.gtimg.cn hf_ES（10秒，国内直连） → Yahoo ES=F（兜底）
 ├─ 标普现货日线  东方财富 push2his kline secid=100.SPX（5分钟，隔夜段锚点）
 ├─ 官方净值     天天基金 fundmobapi（5分钟） → 腾讯净值字段 → HaoETF（三级兜底）
 ├─ 汇率         Yahoo Finance CNY=X（不可达则按 0 变动，日内影响 <0.1%）
 └─ HaoETF 对照  data/sp500.json ← GitHub Actions（schedule + push + 手动触发）
```

## 已知口径说明

- **与券商App的区别**：券商App（同花顺/东财）对跨境 ETF 的溢价率走交易所 IOPV 口径，≈本站「真实溢价率」列；若用「现价 ÷ 最新公布净值」手算会对不上，差的就是隔夜美股涨跌 × 仓位。
- **净值日期**：QDII 净值按美股交易日披露、次日晚间公布；页面「最新净值」滞后一两个交易日常态，属正常。
- **停牌**：高溢价基金会被交易所临时停牌（513500 近期多次 10:30 前停牌），停牌期间现价固定、成交额为 0，页面标注「停牌中」。
- **仓位**：默认 95%（HaoETF 移动平均估算），页面滑块可在 85%–100% 间做敏感性测算。
- **汇率**：Yahoo 不可达时按 0 变动处理，对溢价影响 <0.1%。
- **HaoETF 对照**：来自 haoetf.com 单基金页（Actions 抓取），其用人民币中间价（9:15 更新），与本站存在约 0.1% 系统差。
